# Project brief

Zea’s Bengali columnist archive is a Bengali-first, rights-aware publication archive. The public experience is intentionally evidence-safe: only verified works and permitted text may become public. The first release provides the public information architecture, empty states, protected editorial intake surface, D1/R2 binding configuration, and a relational schema for the archive workflow.

## Current source of truth

No article source pack, verified biography, portrait, publication list, permissions, or contact address was present in the initial workspace. No article records have been invented.
